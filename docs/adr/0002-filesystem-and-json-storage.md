# 本地文件系统加 JSON 存储，不用数据库

这是单人用的本地工具，用户要能直接用 Finder 打开输出目录看产物；数据量是“每视频几十个主题”，没有并发写入。所以元数据一律存 JSON 文件、产物一律落在本地目录，不引入数据库。

## Status

已接受（accepted）。

## 决定

- 不用数据库，也不引入嵌入式索引；所有状态以本地文件 + JSON 表达。
- 视频的 **id 与输出目录在首次生成时确定，之后不再变**。
- 改名只改**显示标题**，不动目录：notes 根目录的 `index.json` 记录 id ↔ 输出目录 ↔ 显示标题，界面按 id 查目录后打开。
- 因此已经发给用户的路径（收藏、脚本、Finder 标签）不会因为改标题而失效。

## 后果

- 路径与 id 一旦冻结就写死在磁盘上，删掉 `index.json` 等于丢失 id 与目录的对应关系；它必须是每次生成都更新的权威映射，不能当成可丢弃的缓存。
- 没有事务：写入要覆盖整个文件，不能磁盘上留半截 JSON。
- 不用为迁移、连接、并发争用写代码；代价是查询靠遍历目录，视频数量上千时才需要重新考虑。
