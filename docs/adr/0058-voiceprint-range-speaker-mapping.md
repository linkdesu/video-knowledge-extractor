# 区间局部簇用声纹归回既有说话人，不再按时间重叠/局部排名铸新号

区间重跑会重新跑分离与二次聚类（ADR-0057），局部编号只是「本次 10 分钟音频内的时长排名」。跨次身份过去靠「同时间 + 同文本」立证据（`alignRangeSpeakers`）：ASR 把相邻两行拼成一条、或重跑端点漂移时这条证据就断了，于是按 ADR-0052 的保守方向铸新号。真机（r91i QA，同一素材同一模型）的结果是：直播 7 人跑 4 个区间变 8 人，6 分钟切段 3 人变 5 人；把这些新编号的 CAM++ 质心与既有编号对比，同一个人的余弦 0.864、拼接碎片 0.74–0.80，而**不同人之间的质心余弦上限只有 0.489**。也就是说，铸出来的「新人」在声纹上是可证的既有说话人。

## Status

已接受（accepted，2026-11-07，r91j / #145）。只改「区间局部簇归谁」这一步的判据；`video.json` 的结构、说话人合并、跨次判重（ADR-0052）与主题分析都不变。

## 决定

1. **同一份 CAM++ 嵌入。** 复用 `asr/embeddings.ts` 的 `extractSegmentEmbeddings`，既有说话人参考与区间局部簇都在同一次分析里即时算，不落任何新结构。
2. **既有说话人参考即时推导。** 从来源媒体音频 + 已有字幕的时间范围算每段嵌入，按说话人聚成归一化质心。媒体整段 wav 只写视频缓存目录（`voiceprint-ref.wav`），质心按「音频 + 参考行集合」缓存；`video.json` 里不新增字段。
3. **决策顺序**（`asr/voiceprint.ts` 的 `mapClustersByVoiceprint`）：
   - 局部簇质心与某位既有说话人余弦 ≥ **0.65** → 归回该编号（阈值落在实测的两团之间：不同人 ≤0.49、同人 0.74–0.86）；
   - 低于阈值但该簇**可信种子时长 ≥ 3 秒**（与 `assignSpeakers` 的保留闸同口径）→ 允许铸新号（真实新人）；
   - 低于阈值且种子不足（1–2 秒碎屑、相邻两行拼接成的碎片）→ 跟随最近质心，**不单独建人**；
   - 整段还没有任何参考 → 不硬塞编号，交给铸号。
4. **接入点。** `pipeline/project-analysis.ts` 在文本/时间对齐（`alignRangeSpeakers`）之后调用 `alignRangeByVoiceprint`：文本已证明的映射不变，只补未证明的局部簇；合并后的映射同时用于跨次判重与落盘编号。
5. **可观测。** `区间说话人对齐` 日志新增 `textAligned`、`references`、`voiceprint`（每个局部簇的余弦、第二名余弦、种子秒数、决策原因），QA 与排查不再需要独立复算。

## Considered Options

- **提高铸号门槛（要求 ≥2 行或 ≥N 秒）**：治标。真机里假新人有 7 行 / 10.8 秒，门槛拦不住。
- **持久化说话人声纹**（写进 `video.json`）：能省一次嵌入计算，但要改 schema 与迁移，本轮明确禁止；参考音频与质心都放在缓存里，删缓存只会重算。
- **用局部排名猜测归属**：正是本票要消除的错误前提。
- **把阈值调到 0.5 硬并**：不同人实测 0.489，没有余量，会错并；0.65 是数据给出的空档。

## 后果

- 区间重跑不再因「文本证据断了」而多出说话人：真机直播 7→7、6 分钟切段 3→3（此前 7→8 / 3→5），且整段 7 位说话人的跨编号质心相似度保持 ≤0.40，没有错并。
- 每次区间分析多一次整段媒体解码（首次，之后读缓存）与既有参考行的嵌入（约 6 秒/250 行）；嵌入按参考行集合缓存，字幕不变时命中。
- 真实新人仍能建号：余弦不达标 + 种子 ≥3 秒。短碎片跟随最近质心，可能把「另一个人的 1 秒应答」并进邻居——方向与 ADR-0052 的「不把局部编号当身份」一致，代价写在这里。
- 与主题无关：主题数翻倍仍归 #150。
