# Windows 安装与使用指南

给不熟悉电脑操作的朋友：这份指南只需要照着点按钮，不用懂任何技术。

## 下载与安装

1. 拿到安装包 `Video Notes-x.x.x-setup.exe`，双击运行。
2. 如果 Windows 弹出蓝色「Windows 已保护你的电脑」（SmartScreen 拦截），点左下角「更多信息」，再点「仍要运行」。这是因为软件没有做数字签名，不是病毒，放心点。
3. 安装向导里可以改安装位置，默认位置不用改，一路「下一步」装完，桌面会出现 Video Notes 图标。

## 第一次启动

1. 双击桌面图标启动。第一次启动时，软件会自动下载识别语音用的模型，大小约 1.1 GB，需要联网，耗时取决于网速。
2. 下载进度显示在「设置」页的模型区域，带逐行日志（下载、校验、解压、安装），不用干等，看到「就绪」就能用了。下载中断了也没关系，下次点「下载模型」会接着下。
3. 下载完成后，「笔记存放位置」默认在「文档」文件夹下的 `video-notes` 目录，所有笔记都存在那里。

## 填写 LLM

笔记由你配置的 AI 接口生成，在「设置」页的 LLM 区域填三个字段：

1. 接口地址：AI 服务的地址，一般以 `https://` 开头，末尾带 `/v1` 的照抄。
2. API key：AI 服务给你的密钥，粘进去，点「保存」。
3. 模型名：填 AI 服务支持的对话模型名；不确定就点「拉取模型」，从列表里选一个。

API key 保存在系统密钥库里，不写在普通文本文件里，可以安心。

## 日志与排错

软件遇到问题（比如提取失败、转写报错）时，在「设置」页操作：

1. 点「复制诊断信息」，内容已经复制到剪贴板，直接发回给我们。
2. 再点「打开日志文件夹」，把里面的文件一起发回来。

发回来之前扫一眼：日志里会有你视频文件的路径，如果路径里有不想暴露的内容，先删掉那几行。

## 卸载

1. 打开 Windows「设置 → 应用 → 已安装的应用」，找到 Video Notes，点「卸载」（老版本系统在「控制面板 → 程序和功能」里卸载）。
2. 卸载只删软件本身。你的笔记在「文档」的 `video-notes` 文件夹里，不会被删，想留着就留着。
